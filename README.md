# NFTAPIApex

NFTAPIApex implements a scalable, High-Performance Event-Driven Architecture with WebSockets Support on a Node Service.

NFTAPIApex is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/NFTAPIApex.git`
2. `cd NFTAPIApex`
3. Install in editable mode: `pip install -e .`

## Configuration

NFTAPIApex is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
